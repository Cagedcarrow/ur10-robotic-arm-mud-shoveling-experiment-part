## 1. 数据含义

- `Act_q0..Act_q5`：六个关节的实际关节角。
- `Tgt_q0..Tgt_q5`：六个关节的目标角度，用于评估跟踪误差。
- `Act_qd0..Act_qd5`：六个关节的实际角速度，是平滑性和阶段切换的主运动信号。
- `Act_X/Y/Z` 与 `Act_RX/RY/RZ`：TCP 位置与姿态，用于描述末端空间状态。
- `Act_dX/dY/dZ` 与 `Act_dRX/dRY/dRZ`：TCP 线速度与角速度，用于描述末端空间运动强度。
