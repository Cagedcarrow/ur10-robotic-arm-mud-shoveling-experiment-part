# 面向铲泥实验的姿态补偿力投影称重方法

## 摘要

机械臂铲泥实验中的末端载荷估计同时受到泥重量、流体阻力与姿态变化的共同影响，因此直接以局部三轴力模长作为称重指标通常缺乏稳定的物理解释。为提高估重结果对实际载荷变化的指示性，本文构建了一种姿态补偿力投影称重方法。该方法将末端力传感器测得的局部三轴力通过工具几何关系映射至机器人基坐标系，并以重力方向分量作为主称重通道；随后在任务末段构造最终称重点，并在其之前选取低载、姿态相近且局部稳定的参考状态，以估计相对质量变化。代表性算例表明，该方法能够将参考状态误选所导致的公斤级虚高结果修正为数百克以内的合理量级。对 8 个实验会话的批量分析进一步说明，参考状态选择对估重结果具有决定性影响，而姿态补偿后的重力方向投影能够为铲泥实验中的相对载荷分析提供更具一致性的度量框架。

## 1. 方法背景与问题定义

在铲泥实验中，末端力信号并不等同于泥重量本身。三轴力同时反映了泥对铲具的重力作用、铲入与抽离阶段的泥浆阻力，以及工具姿态变化导致的受力投影改变。若直接采用三轴力模长

```text
|F| = sqrt(Fx^2 + Fy^2 + Fz^2)
```

作为称重指标，则上述不同来源的力学成分将被混合到同一个标量中，从而削弱其作为有效载荷表征量的意义。尤其是在实验前段仍存在明显接触阻力时，局部稳态中的 `|F|` 甚至可能高于铲泥完成后的最终称重点，导致相对质量差值出现方向错误。

因此，铲泥场景中的称重问题更适宜被定义为一个“姿态补偿后的相对载荷估计问题”，而非一个“由任意瞬时三轴力直接读取质量”的问题。该问题包含两个彼此耦合的子任务：其一是从局部测力中分离出与重力方向相关的有效分量，其二是在复杂接触过程中构造可用于比较的参考状态与最终状态。

## 2. 坐标投影称重原理

该方法的核心思想是将力传感器坐标系下的测量值变换到机器人基坐标系，并以基坐标系重力方向上的分量刻画有效载荷。由于传感器安装在铲具结构内部，其局部坐标轴与工具参考系并不共线，也不与机器人基坐标系直接对齐，因此必须先进行姿态补偿，再讨论重量相关分量。

设局部测力向量为

```text
F_sensor = [Fx, Fy, Fz]^T
```

设工具参考系相对于机器人基坐标系的姿态旋转为 `R_base_tcp`，传感器坐标系相对于工具参考系的固定旋转为 `R_tcp_sensor`，则传感器相对于机器人基坐标系的姿态为

```text
R_base_sensor = R_base_tcp · R_tcp_sensor
```

据此，局部测得的三轴力可被变换为

```text
F_base = R_base_sensor · F_sensor
```

其中

```text
F_base = [F_base,x, F_base,y, F_base,z]^T
```

在本实验构型下，传感器与工具参考系之间的静态旋转矩阵为

```text
R_sensor_to_tcp =
[[-0.000003, -0.819151,  0.573577],
 [ 0.000002,  0.573577,  0.819151],
 [-1.000000,  0.000004,  0.000000]]
```

其逆变换可写为

```text
R_tcp_to_sensor =
[[-0.000003,  0.000002, -1.000000],
 [-0.819151,  0.573577,  0.000004],
 [ 0.573577,  0.819151,  0.000000]]
```

上述矩阵表明，传感器局部 `z` 轴与工具参考系主轴并不重合，传感器三轴力中任一分量都可能在基坐标系重力方向上产生贡献。因此，相比直接使用 `|F|`，将局部测力投影为 `F_base,z` 更能体现与实际载荷变化直接相关的力学信息。基于这一理由，本文将 `F_base,z` 作为主称重通道，而将 `|F|` 保留为辅助诊断量，用于识别接触阻力或异常高载阶段。

## 3. 稳态称重与参考状态构造

仅有姿态补偿仍不足以形成可靠称重结果，因为在实验过程中，末端受力还受到显著的时间依赖效应影响，特别是在铲入、抽离和泥浆分离阶段。因此，称重比较必须建立在局部稳态之上，而不能在剧烈接触区直接比较瞬时力值。

本文将目标关节在短时间内近似不变的区间视为局部稳态，其物理含义在于：当控制目标趋于稳定时，机械臂姿态变化减弱，运动诱导的附加扰动相对较小，更适合进行载荷比较。任务后段最后出现的长稳态区间被定义为最终称重点，因为该状态最接近“铲泥完成后保持姿态以观察载荷”的实验语义。

参考状态的构造是该方法区别于简单稳态差分的关键。若将早期任意稳态都视为空载基线，则高阻力停顿段极易被误判为参考状态，从而导致重量结果虚高。因此，参考状态应同时满足三个条件：第一，其时间位置应位于最终称重点之前；第二，其姿态应与最终称重点足够接近，以降低几何投影差异；第三，其载荷水平与波动幅度应尽可能低，以减少泥浆阻力残留。

据此，本文采用“低载候选参考段”思想，即优先在最终称重点之前寻找载荷较低、姿态相近且局部稳定的窗口作为参考。与此同时，参考窗口既不能过度靠近最终称重点，否则过渡区中的力学残留会被误并入基线；也不能落在实验前段的高阻力区域，否则将显著抬高参考载荷，并诱发不合理的公斤级估计。

## 4. 质量估计模型

设参考状态在重力方向上的平均投影力为 `F_ref`，最终称重点在同一方向上的平均投影力为 `F_final`，则相对载荷变化定义为

```text
Delta F = F_final - F_ref
```

在当前实验语义下，`Delta F` 表示铲具在最终称重点相对于参考状态所新增或减少的等效重力载荷。为避免不同坐标定义下的符号约定影响质量量级解释，本文在质量换算时采用力差绝对值：

```text
m = |Delta F| / g
```

其中 `g = 9.80665 m s^-2`。若以克为单位表示，则有

```text
m_g = 1000 · |Delta F| / g
```

### 4.1 代表性算例

以会话 `2026-05-01_19-57-41` 为例，参考窗口位于 `3195.320–3195.768 s`，最终称重点位于 `3196.832–3202.632 s`。参考状态的局部平均力为

```text
Fx = 4.717 N
Fy = 17.981 N
Fz = 46.696 N
|F| = 50.260 N
F_base,z = -8.034 N
```

最终称重点的局部平均力为

```text
Fx = 7.122 N
Fy = 23.244 N
Fz = 48.549 N
|F| = 54.425 N
F_base,z = -5.036 N
```

因此，

```text
Delta F = F_final - F_ref
        = (-5.036) - (-8.034)
        = 2.998 N
```

对应的相对质量变化为

```text
m_g = 1000 × 2.998 / 9.80665
    = 305.70 g
```

这一数量级与实验中对“数百克相对载荷变化”的预期一致，说明姿态补偿后的重力方向投影能够在该代表性会话中提供具有物理意义的称重结果。

## 5. 误差来源与方法边界

该方法的第一项误差来源来自工具参考系与传感器参考系之间的几何关系。若姿态参考的实际定义与分析中使用的工具参考系不一致，则姿态补偿后的投影方向将产生系统性偏差，从而直接影响 `F_base,z` 的物理解释。第二项误差来源为力传感器零点漂移。当实验前后零点发生不可忽略的变化时，即使真实泥重量未改变，参考状态与最终状态之间的相对力差仍可能产生整体偏移。

第三项误差来源是泥浆阻力残留。尽管参考状态选择已尽量避免高阻力区间，但在泥浆高度黏滞、分离速度较慢或工具抽离不充分的情况下，局部低载窗口仍可能包含残余阻力，从而改变参考基线。第四项误差来源是姿态建模误差。若姿态观测存在偏差，或工具在加载下发生微小弹性变形，则静态几何关系与真实受力方向之间可能产生不可忽略的偏离。

此外，参考状态构造本身具有启发式特征。尽管通过姿态接近度、低载程度、时间邻近性与局部稳定性可以显著降低高阻力稳态被误判为空载参考的风险，但这一过程仍不等同于经过外部标定得到的最优估计器。因此，方法的可靠性依赖实验流程的相对一致性，并需在不同泥浆条件、不同铲具结构与不同控制策略下进一步验证。

## 6. 结果解释框架

不同实验会话之间的重量差异，应首先被理解为“参考状态与最终称重点之间的相对载荷差异”，而不应直接等同于某一时刻的绝对静质量。若结果达到公斤级且明显背离实验直觉，则通常首先应怀疑参考状态失配，而非直接解释为真实载荷异常。这类情形往往出现在参考状态仍位于高阻力区、姿态与最终称重点显著不一致，或参考窗口过早、过晚而未能代表弱载基线时。

## 7. 结论

本文提出了一种面向机械臂铲泥实验的姿态补偿力投影称重方法，其核心在于将局部三轴测力转化为机器人基坐标系下的重力方向分量，并在最终称重点之前构造低载且姿态相近的参考状态，以估计相对质量变化。代表性算例显示，该方法能够得到 `305.70 g` 量级的合理估计；批量结果进一步表明，在参考状态构造得到修正后，异常的公斤级虚高结果可显著回落至更可信的区间。

需要强调的是，该方法旨在提供一种结构化的相对称重框架，而非在任意场景下给出无条件成立的绝对质量真值。其有效性仍依赖于姿态参考定义、力传感器稳定性以及参考状态选择的合理性。因此，在实际应用中，方法结果应结合具体实验过程、工具构型与误差边界进行综合解释。
