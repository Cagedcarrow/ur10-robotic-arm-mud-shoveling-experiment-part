# 本次任务总结

## 1. 任务目标

修复批量称重中参考段选择错误导致的公斤级假结果，使 `data` 目录下各实验会话的重量变化估计回到合理量级。

## 2. 根因分析

原有批处理策略默认把“最终称重点前一个长稳态段”直接作为 `0 g` 参考段。这个规则在首个样本上有效，但在其余多个会话上失效，原因是：

- 被选中的前一稳态段仍处于高载荷或强接触阶段
- 这些错误参考段与最终段姿态差异很大
- 最终段之前真正更合理的低载短窗口没有被长稳态检测抓到

## 3. 修改文件清单

- `data/analysis/analyze_force_weight.py`
- `data/analysis/analyze_all_force_weight.py`
- `docs/task_logs/2026-05-05_reference_selection_fix.md`

## 4. 新增功能

- 将参考段选择改为“低载候选参考段”策略
- 先评估长稳态候选，再补充搜索最终段前的低载滑窗
- 为参考窗口增加最小时间间隔，避免把最终前过渡区误当参考
- 批量汇总新增参考类型、姿态距离、参考/最终基坐标系力值和风险等级

## 5. 核心实现逻辑

- 继续使用现有模型坐标投影方法计算 `force_base_z`
- 对长稳态候选按姿态距离、载荷差、时间距离和波动性综合评分
- 若长稳态候选明显不合理，则在最终段前固定时间范围内搜索低载短窗口
- 低载窗口必须满足：
  - 与最终段保持最小时间间隔
  - 姿态接近最终段
  - `force_base_z` 波动较小
- 批量结果优先选得分最低且风险更低的参考候选
